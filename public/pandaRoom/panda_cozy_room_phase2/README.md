# Panda Cozy Room — Phase 2 (5 editable SVG assets)

These five SVGs use the same 1080 × 1920 coordinate space as Phase 1.

11_coffee_cup.svg — cup, handle, saucer, shadow are independent groups.
12_coffee_steam.svg — three separately animatable steam wisps.
13_korean_study_book.svg — open book, pages, bookmark, spine.
14_potted_plant.svg — stems, individual leaf clusters, pot.
15_wall_clock.svg — frame, ticks, hour hand, minute hand. Clock hands rotate around (905,475).

Suggested z-order: Phase 1 background -> Phase 1 furniture -> book / plant / clock -> cup -> steam. Depending on placement, put cup above the table surface.

Animation guidance: steam rises and fades in staggered loops; leaves rotate gently around stems; clock hands rotate around center; coffee cup can be parented to panda's hand during drinking.

These are editable SVG graphics, NOT an exported .riv animation. Imported groups may require setting pivots in Rive.
